# Track: Gemini googleSearch grounding

Source: `cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search`, callsphere.ai guide, oneuptime guide, Mintlify generative-ai reference

What this track yielded:
1. The `googleSearch` (Gemini 2.5) vs `googleSearchRetrieval` (Gemini 1.5) distinction.
2. The `dynamic_threshold` semantics: 0=always search, 1=never search, default 0.3.
3. The 1M-queries-per-day quota.
4. The "cannot combine search with non-search tools" limitation.
5. The recommended `temperature=1.0` setting for grounding.
