# Track: Microsoft Bing Web Search API

Source: `learn.microsoft.com/en-us/azure/foundry-classic/agents/how-to/tools-classic/bing-grounding`

What this track yielded:
1. The `count`, `freshness`, `market`, `setLang`, `responseFilter`, `cc` parameter table.
2. The `freshness` enum: `Day` / `Week` / `Month` / `YYYY-MM-DD..YYYY-MM-DD` / single date.
3. The `market` format `<lang>-<country>` and the recommendation to always specify it.
4. Note that Bing AI may not use all returned search results — design for partial consumption.
