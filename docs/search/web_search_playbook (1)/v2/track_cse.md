# Track: Google Programmable Search (CSE)

Source: `developers.google.com/custom-search/docs/xml_results`, `developers.google.com/custom-search/v1/overview`, glama.ai MCP server docs

What this track yielded:
1. The full operator table: site:, -, "…", +, intitle:, inurl:, OR, more:.
2. The XML/JSON request parameter reference: cx, q, num, start, filter, hq, lr, cr, gl, safe, exactTerms, orTerms, excludeTerms, dateRestrict.
3. The 2027 sunset warning: CSE is closed to new customers, existing must migrate by 2027-01-01.
4. URL-escape rules: `+` → `%2B`, `"` → `%22`, `-` → `%2D`, `:` is fine in path part.
