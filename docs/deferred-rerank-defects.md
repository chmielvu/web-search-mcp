# Deferred Rerank Pipeline Defects

The following defects were identified in the `kindly_web_search_mcp_server/rerank` package during the RAG architectural review (September 2026). They are documented here for future, independent remediation.

## 1. Top-k Backfill Bypass
- **Location**: `rerank/core.py` (top-k backfill loop).
- **Issue**: When `top_k > len(final_results)`, the pipeline backfills candidates exclusively from `bi_candidates` and the raw `candidates` list. It completely skips `cross_outcome.full_candidates` and `llm_outcome.full_candidates`.
- **Impact**: Candidates ranked 16-30 by the cross-encoder or RankLLM are discarded in favor of lower-quality candidates from the raw retrieval pool.

## 2. Parse-Error Chain Kill (Fallback Resilience)
- **Location**: `rerank/providers.py` (`_parse_rerank_result` and `rerank_with_provider_fallback`).
- **Issue**: `_parse_rerank_result` is executed *inside* the fallback executor loop. If a provider (like Cohere or Voyage) returns malformed JSON or unexpected schema, a `ValueError` is raised. The unified inference engine treats `ValueError` as a non-retryable exception.
- **Impact**: A single malformed JSON response instantly kills the entire cross-encoder fallback chain, preventing the system from trying secondary providers and causing the search to fail open abruptly.

## 3. MMR Relevance Inversion
- **Location**: `rerank/core.py` (MMR relevance score assignment).
- **Issue**: The diversity selection (MMR) relies heavily on `cross_relevance_score` to determine the initial greedy selection, or falls back to a uniform/positional score.
- **Impact**: Because it uses the prior stage's cross-encoder score rather than the terminal active RankLLM ordering, MMR can subvert the global permutation painstakingly generated by the listwise LLM stage on step 0, displacing the LLM's #1 pick.

## 4. Unclamped Entity Boosts
- **Location**: `rerank/stages.py` (`apply_entity_overlap_boost`).
- **Issue**: The entity overlap boost calculation (`float(candidate.score) + (weight * overlap)`) lacks a boundary clamp.
- **Impact**: Boosted scores can silently exceed the documented `[0.0, 1.0]` boundary range established for normalized results.
