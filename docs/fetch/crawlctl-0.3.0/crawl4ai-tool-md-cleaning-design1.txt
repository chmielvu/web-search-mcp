Each Markdown file has YAML front matter containing source, title, UTC crawl time, content family,
chosen extractor, cleaner, score and signal breakdown, counts, SHA-256 content hash, headings,
links, edits, warnings, and publication state. Filenames include a URL hash to prevent collisions.

## Cleaner modes

* `native` (default) preserves code and tables, normalizes Unicode/mojibake, removes dangerous HTML,
  repairs headings/fences, canonicalizes links and tracking parameters, applies content-family junk
  rules, removes short link-heavy blocks and repeated site blocks, then scores the result.
* `native+markdownchef` performs the same cleaning and adds Chonkie MarkdownChef structural counts.
  **MarkdownChef is a parser/preprocessor, not a sanitizer**: current Chonkie returns a
  `MarkdownDocument` describing tables, code, images, and text regions without rewriting content.
  Treating it as the cleaner would be both ineffective and version-fragile.

Trafilatura is used only when the `extract` extra is installed and Crawl4AI returns HTML. Every
candidate is cleaned and independently scored; score wins, with length only as a tie-breaker.

## Security and operations

Use Crawl4AI 0.9+ authentication and its upstream SSRF controls. `execute_js` and declarative hooks
are still governed by the instance feature flags. The gateway follows no HTTP redirects itself,
redacts tokens from errors, bounds a scrape to 100 URLs, restricts generic operations to a fixed
endpoint map, and never accepts arbitrary endpoint paths. Output writes are atomic.

    "â€œ": "“",

def block_hash(text: str) -> str:
    normalized = re.sub(r"\W+", " ", text.casefold()).strip()
    return hashlib.sha256(normalized.encode()).hexdigest()[:20]


def _url(value: str, base: str) -> str:
    absolute = urljoin(base, html.unescape(value))
    parts = urlsplit(absolute)
    if parts.scheme not in {"http", "https", "mailto"}:
        return ""
    query = [
        (k, v)
        for k, v in parse_qsl(parts.query, keep_blank_values=True)
        if not k.lower().startswith("utm_") and k.lower() not in _TRACKING
    ]
    return urlunsplit(
        (parts.scheme, parts.netloc, parts.path, urlencode(query), parts.fragment)
    )


def _outside_fences(lines: list[str]):
    opened: tuple[str, int] | None = None
    for index, line in enumerate(lines):
        match = _FENCE.match(line)
        inside = opened is not None
        yield index, line, inside
        if match:
            marker = match.group(1)
            if opened is None:
                opened = (marker[0], len(marker))
            elif marker[0] == opened[0] and len(marker) >= opened[1]:
                opened = None


def clean_markdown(markdown: str, options: CleaningOptions) -> CleanResult:
    if options.link_mode not in {
        "keep",
        "text",
        "drop",
    } or options.image_policy not in {"keep", "alt", "drop"}:
        raise ValueError("invalid link_mode or image_policy")
    edits: dict[str, int] = {}
    text = markdown.replace("\r\n", "\n").replace("\r", "\n")
    for bad, good in _MOJIBAKE.items():
        if bad in text:
            edits["mojibake"] = edits.get("mojibake", 0) + text.count(bad)
            text = text.replace(bad, good)
    text = unicodedata.normalize("NFC", _ZERO.sub("", text)).replace("\u00a0", " ")
    text, count = _HTML_BLOCK.subn("", text)
    edits["html_blocks"] = count
    profile, confidence = detect(text, options.content_type)
    lines = text.splitlines()
    output: list[str] = []
    hashes: list[str] = []
    heading_seen = False
    last_level = 0
    fence_open = False
    for _, original, inside in _outside_fences(lines):
        line = original
        marker = _FENCE.match(line)
        if marker:
            fence_open = not fence_open
            output.append(line.rstrip())
            continue
        if inside:
            output.append(line.rstrip())
            continue
        line = html.unescape(line)
        line, n = _TAG.subn("", line)
        edits["html_tags"] = edits.get("html_tags", 0) + n
        heading = re.match(r"^(#{1,6})\s+(.*)$", line)
        if heading:
            level = len(heading.group(1))
            if level == 1 and heading_seen:
                level = 2
                edits["extra_h1"] = edits.get("extra_h1", 0) + 1
            if last_level and level > last_level + 1:
                level = last_level + 1
                edits["heading_gaps"] = edits.get("heading_gaps", 0) + 1
            heading_seen |= level == 1
            last_level = level
            line = "#" * level + " " + heading.group(2).strip(" #")

        def image_replace(match: re.Match[str]) -> str:
            alt, target = match.groups()
            if options.image_policy == "drop":
                return ""
            if options.image_policy == "alt":
                return alt
            safe = _url(target.split()[0], options.source_url)
            return f"![{alt}]({safe})" if safe else alt

        line = _IMAGE.sub(image_replace, line)

        def link_replace(match: re.Match[str]) -> str:
            label, target = match.groups()
            if options.link_mode == "drop":
                return ""
            if options.link_mode == "text" or target.startswith("#"):
                return label
            safe = _url(target, options.source_url)
            return f"[{label}]({safe})" if safe else label

        line = _LINK.sub(link_replace, line)
        if options.citations == "strip" or (
            options.citations == "auto" and profile.name == "wiki"
        ):
            line, n = _CITE.subn("", line)
            edits["citations"] = edits.get("citations", 0) + n
        stripped = line.strip()
        words = re.findall(r"\b[\w'-]+\b", stripped)
        line_links = list(_LINK.finditer(stripped))
        link_chars = sum(len(m.group(0)) for m in line_links)
        link_density = link_chars / max(1, len(stripped))
        digest = block_hash(stripped) if stripped else ""
        if stripped and len(words) <= 80:
            hashes.append(digest)
        junk = any(pattern.fullmatch(stripped) for pattern in profile.patterns)
        # A lone reference link is content. Link-density becomes a useful nav
        # signal only for link lists or lines containing several destinations.
        link_junk = (
            (len(line_links) >= 2 or bool(re.match(r"^\s*[-*+]\s+", line)))
            and len(words) <= 12
            and link_density > profile.link_tolerance
        )
        repeated = digest in options.repeated_hashes and len(words) <= 80
        if junk or link_junk or repeated:
            reason = (
                "pattern"
                if junk
                else "link_density"
                if link_junk
                else "site_repetition"
            )
            edits[reason] = edits.get(reason, 0) + 1
            continue
        if output and stripped and stripped == output[-1].strip():
            edits["duplicates"] = edits.get("duplicates", 0) + 1
            continue
        output.append(line.rstrip())
    cleaned = re.sub(r"\n{3,}", "\n\n", "\n".join(output)).strip()
    warnings: list[str] = []
    # Parse as a safety oracle; preserve source formatting rather than re-rendering tokens.
    try:
        MarkdownIt("commonmark").parse(cleaned)
    except Exception as exc:  # pragma: no cover
        warnings.append(f"markdown_parse: {exc}")
    if fence_open:
        cleaned += "\n```"
        edits["fence_repairs"] = 1
        warnings.append("closed an unterminated fence")
    return CleanResult(
        cleaned + "\n", profile.name, confidence, edits, hashes, warnings
    )


def score_markdown(result: CleanResult) -> dict[str, object]:
    text = result.text
    profile, _ = detect(text, result.content_type)
    words = re.findall(r"\b[\w'-]+\b", re.sub(r"[`#*_[\]()]", " ", text))
    links = list(_LINK.finditer(text))
    headings = re.findall(r"^(#{1,6})\s+", text, re.M)
    word_signal = min(1.0, len(words) / profile.target_words)
    sentence_count = max(1, len(re.findall(r"[.!?](?:\s|$)", text)))
    prose = min(1.0, (len(words) / sentence_count) / 16)
    link_density = sum(len(x.group(0)) for x in links) / max(1, len(text))
    link_signal = max(0.0, 1 - link_density / profile.link_tolerance)
    structure = (
        0.4
        + (0.35 if headings else 0)
        + (0.25 if sum(h == "#" for h in headings) <= 1 else 0)
    )
    hygiene = 1.0 - min(1.0, len(_TAG.findall(text)) / 5)
    value = round(
        100
        * (
            0.28 * word_signal
            + 0.25 * prose
            + 0.17 * link_signal
            + 0.15 * structure
            + 0.15 * hygiene
        )
    )
    if len(words) < profile.min_words:
        value = min(value, 69)
    return {
        "value": value,
        "band": "publish" if value >= 70 else "review" if value >= 45 else "reject",
        "signals": {
            "words": round(word_signal, 3),
            "prose": round(prose, 3),
            "links": round(link_signal, 3),
            "structure": round(structure, 3),
            "hygiene": round(hygiene, 3),
        },
        "word_count": len(words),
        "link_density": round(link_density, 4),
    }

@dataclass(slots=True)
class Crawl4AIClient:
    base_url: str
    token: str | None = None
    timeout: float = 120.0

    def _headers(self) -> dict[str, str]:
        return {"Authorization": f"Bearer {self.token}"} if self.token else {}

    async def request(
        self,
        method: str,
        path: str,
        *,
        json: dict[str, Any] | None = None,
        params: dict[str, Any] | None = None,
    ) -> Any:
        try:
            async with httpx.AsyncClient(
                base_url=self.base_url.rstrip("/"),
                headers=self._headers(),
                timeout=httpx.Timeout(self.timeout, connect=10),
                follow_redirects=False,
            ) as client:
                response = await client.request(method, path, json=json, params=params)
                response.raise_for_status()
                content_type = response.headers.get("content-type", "")
                return response.json() if "json" in content_type else response.content
        except httpx.HTTPStatusError as exc:
            detail = exc.response.text[:1000]
            raise Crawl4AIError(
                f"Crawl4AI {exc.response.status_code} at {path}: {detail}"
            ) from exc
        except httpx.HTTPError as exc:
            raise Crawl4AIError(
                f"Crawl4AI unavailable at {self.base_url}: {exc}"
            ) from exc

    async def crawl(
        self,
        urls: list[str],
        *,
        browser_config: dict[str, Any] | None = None,
        crawler_config: dict[str, Any] | None = None,
        crawler_configs: list[dict[str, Any]] | None = None,
        hooks: dict[str, Any] | None = None,
    ) -> list[dict[str, Any]]:
        payload: dict[str, Any] = {
            "urls": urls,
            "browser_config": browser_config or {},
            "crawler_config": crawler_config or {},
        }
        if crawler_configs is not None:
            payload["crawler_configs"] = crawler_configs
        if hooks is not None:
            payload["hooks"] = hooks
        data = await self.request("POST", "/crawl", json=payload)
        results = data.get("results", data) if isinstance(data, dict) else data
        return results if isinstance(results, list) else [results]

    async def inspect(self) -> dict[str, Any]:
        health = await self.request("GET", "/health")
        schema = await self.request("GET", "/schema")
        try:
            hooks = await self.request("GET", "/hooks/info")
        except Crawl4AIError as exc:
            hooks = {"unavailable": str(exc)}
        return {"health": health, "config_schema": schema, "hooks": hooks}

    async def operation(self, operation: str, arguments: dict[str, Any]) -> Any:
        """Expose bounded ancillary endpoints without an arbitrary URL proxy."""
        table: dict[str, tuple[str, str, str]] = {

                raise ValueError("arguments.id is required")
            prefix = {
                "crawl_job_status": "/crawl/job/",
                "llm_job_status": "/llm/job/",
                "artifact": "/artifacts/",
            }[operation]
            return await self.request("GET", prefix + ident)
        if operation == "ask":
            return await self.request("GET", "/ask", params=arguments)
        if operation == "llm":
            url = quote(str(arguments.pop("url", "")), safe="")
            return await self.request("GET", f"/llm/{url}", params=arguments)
        if operation not in table:
            raise ValueError(
                f"Unknown operation {operation!r}; allowed: {sorted([*table, 'ask', 'llm', 'crawl_job_status', 'llm_job_status', 'artifact'])}"
            )
        method, path, _ = table[operation]
        return await self.request(method, path, json=arguments)

            "content_type must be auto, docs, wiki, blog, news, or generic"

    scores = {
        kind: sum(lowered.count(signal) > 0 for signal in signals)
        for kind, signals in SIGNALS.items()
    }
    kind = requested if requested != "auto" else max(scores, key=scores.get)
    if requested == "auto" and scores[kind] == 0:
        kind = "generic"
    confidence = 1.0 if requested != "auto" else min(1.0, scores.get(kind, 0) / 3)
    minimum, target, tolerance = _LIMITS[kind]
    raw = PATTERNS["generic"] + PATTERNS.get(kind, [])
    return Profile(
        kind,
        minimum,
        target,
        tolerance,
        tuple(re.compile(rf"^\s*(?:{p})\s*[:?.!]*\s*$", re.I) for p in raw),
    ), confidence

"""Atomic content-address-aware Markdown document store."""

from __future__ import annotations
import hashlib
import json
import os
import re
import tempfile
from pathlib import Path
from typing import Any
from urllib.parse import urlsplit
import yaml


def _slug(url: str) -> tuple[str, str]:
    parsed = urlsplit(url)
    host = re.sub(r"[^a-z0-9.-]+", "-", parsed.netloc.lower()).strip("-") or "unknown"
    stem = re.sub(
        r"[^a-z0-9]+", "-", (parsed.path.strip("/") or "index").lower()
    ).strip("-")
    suffix = hashlib.sha256(url.encode()).hexdigest()[:10]
    return host, f"{stem[:100]}-{suffix}.md"


def _atomic_write(path: Path, value: str) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, temporary = tempfile.mkstemp(dir=path.parent, prefix=".tmp-")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as handle:
            handle.write(value)
            handle.flush()
            os.fsync(handle.fileno())
        os.replace(temporary, path)
    finally:
        if os.path.exists(temporary):
            os.unlink(temporary)


class DocumentStore:
    def __init__(self, root: str | Path):
        self.root = Path(root).expanduser().resolve()
        self.root.mkdir(parents=True, exist_ok=True)
        self.manifest_path = self.root / "manifest.json"
        try:
            self.manifest = json.loads(self.manifest_path.read_text())
        except (FileNotFoundError, json.JSONDecodeError):
            self.manifest = {"version": 1, "pages": {}}

    def write(
        self, url: str, markdown: str, metadata: dict[str, Any], quarantine: bool
    ) -> Path:
        host, name = _slug(url)
        path = self.root / ("quarantine" if quarantine else "pages") / host / name
        body = (
            "---\n"
            + yaml.safe_dump(metadata, sort_keys=False, allow_unicode=True).rstrip()
            + "\n---\n\n"
            + markdown
        )
        _atomic_write(path, body)
        self.manifest["pages"][url] = {
            "status": metadata["status"],
            "file": str(path.relative_to(self.root)),
            "score": metadata["score"]["value"],
            "content_hash": metadata["content_hash"],
        }
        return path

    def finish(self, report: dict[str, Any]) -> None:
        _atomic_write(
            self.manifest_path,
            json.dumps(self.manifest, indent=2, ensure_ascii=False) + "\n",
        )
        _atomic_write(
            self.root / "report-latest.json",
            json.dumps(report, indent=2, ensure_ascii=False) + "\n",
        )

# Research notes and 2026 design decisions

Research was checked against upstream projects on 2026-09-14. The web search service was unavailable,
so the implementation was verified from current upstream repositories and official documentation.

## Crawl4AI self-hosted surface

Crawl4AI's current Docker server exposes `POST /crawl` and `/crawl/stream`; convenience endpoints
`/md`, `/html`, `/screenshot`, `/pdf`, and feature-gated `/execute_js`; `/schema`, `/hooks/info`,
`/health`, `/ask`, `/llm/{url}`; background `/crawl/job` and `/llm/job` enqueue/poll endpoints;
artifact retrieval; token/config endpoints; and administrative observability routes. The MCP exposes
acquisition through its specialized tool and safe-lists useful content endpoints in one generic tool.
Monitor/admin actions are intentionally not agent tools: restarting browsers and resetting server
stats are operational privileges, not document acquisition capabilities.

Do not mirror hundreds of config properties into a second stale type system. The official server's
`/schema` response is the source of truth, while opaque config dictionaries preserve access to the
complete connected-version surface. This also handles mixed-version deployments better than a
hard-coded model. See the [official self-hosting guide](https://docs.crawl4ai.com/core/self-hosting/),
[CrawlerRunConfig reference](https://docs.crawl4ai.com/api/parameters/), and
[markdown generation guide](https://docs.crawl4ai.com/core/markdown-generation/).

## Extraction and cleaning findings

No single postprocessor reliably solves all page families. The robust pattern is layered:

1. DOM/render-aware extraction removes most chrome. Crawl4AI's pruning/BM25 filters belong here.
2. Independent main-text extraction is a useful candidate, not an unquestioned replacement.
   Trafilatura exposes precision/recall controls and retains links/tables in Markdown. Its published
   evaluation reports strong main-text extraction performance; see the
   [Trafilatura evaluation](https://trafilatura.readthedocs.io/en/latest/evaluation.html) and
   [Barbaresi 2021 paper](https://aclanthology.org/2021.acl-demo.15/).
3. Markdown-aware normalization must avoid AST reserialization because serializers can alter code,
   tables, whitespace, and extensions. This project uses markdown-it-py as a parse oracle and makes
   fence-aware, line-local edits. See [markdown-it-py](https://markdown-it-py.readthedocs.io/).
4. Short-block text/link density catches menus; cross-page repetition catches templates that look
   linguistically valid. These ideas follow boilerplate-removal work such as
   [Kohlschütter et al.](https://dl.acm.org/doi/10.1145/1718487.1718542) and
   [jusText](https://corpus.tools/wiki/Justext).
5. Quality must be multi-signal and explainable. Length alone rewards boilerplate; link density alone
   punishes documentation and wikis. The score therefore combines calibrated length, prose shape,
   links, heading structure, and hygiene, records every signal, and quarantines rather than deletes.

Content-family rules address docs navigation/copy controls, wiki chrome/citations, blog subscription
and related-post elements, and news carousels/credits. Two-pass mode learns blocks present on at least
three and half of the pages from a host. It is deliberately conservative: short blocks only, hashes
over normalized exact content, and no fuzzy deletion that might erase recurring API signatures.

## Chonkie/Chunkie correction

The library is **Chonkie**, and its current `MarkdownChef` parses Markdown into tables, code blocks,
images, and text chunks. It does not expose `clean`, `cook`, `sanitize`, or `transform`, and its
returned document retains the original content. The supported integration calls its real `parse`
API after native cleaning and records structural diagnostics. See Chonkie's
[MarkdownChef documentation](https://docs.chonkie.ai/oss/chefs/markdownchef) and
[source](https://github.com/chonkie-inc/chonkie/blob/main/src/chonkie/chef/markdown.py).

## Practitioner pipeline and evaluation

Production pipelines commonly separate immutable acquisition/provenance from transformation and
indexing. This implementation writes content hashes and a URL manifest for incremental comparison,
keeps low-confidence documents in quarantine, and emits a run report. A downstream system can use
the hash as an idempotency key and choose its chunker independently.

Before deployment, create a stratified gold set (at least 20 pages for each actual site family), mark
body spans and boilerplate spans, then measure body-word recall and boilerplate precision. Tune
thresholds per corpus, inspect score distributions rather than assuming 70/45 universally, and
regression-test code fences, tables, multilingual prose, link targets, paywalls, empty/error pages,
and repeated legitimate notices. Treat the heuristic score as triage—not factuality, authority, or a
substitute for crawl success and HTTP status policy.
